# TCC-HUST-
Aplicação web de comércio eletrônico  , Trabalho de Conclusão de Curso (TCC) do curso Técnico em Informática para Internet na Etec Batatais (2026).  O projeto simula a experiência completa de uma loja virtual moderna com foco em identidade visual urbana  performance e responsividade para desktop e dispositivos móveis.
